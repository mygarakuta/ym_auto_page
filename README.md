# 자동 페이지 넘김 (ym_auto_page)

뷰어를 연 상태에서 정한 시간(초)마다 다음 페이지로 자동으로 넘겨 주는 BookOasis 플러그인입니다.

## 설치

1. `ym_auto_page` 폴더를 `plugins/metadata/` 아래에 복사하고 서버를 재시작합니다.
2. 환경설정 > 플러그인 설정에서 **자동 페이지 넘김**을 켭니다.
3. (권장) 내 설정 > 홈 화면 플러그인 배치 모드를 켜고, 홈 화면의 "+ 위젯 추가"에서 **자동 페이지 넘김**을 추가합니다.
   이렇게 하면 앱을 열 때마다 엔진이 자동으로 올라옵니다. 위젯을 쓰지 않는다면 사이드바의 **자동 페이지 넘김** 화면을 한 번 연 뒤 뷰어를 여세요.

## 사용

- 뷰어에서 `Alt+A`(관리자 설정으로 변경 가능) 또는 화면 왼쪽 아래 ▶ 버튼으로 시작/정지합니다.
- `−` / `+` 로 간격을 바꾸고, 화면 아래쪽 얇은 막대로 남은 시간을 봅니다.
- 직접 페이지를 넘기거나 화면을 만지면 카운트다운이 처음부터 다시 시작합니다(끌 수 있음).
- `Esc`, 뷰어 닫기, 다른 탭으로 전환(일시 정지)에도 반응합니다.
- 조작 버튼의 `⌄`를 누르면 지름 22px짜리 점으로 접힙니다. 멈춰 있으면 ⏱, 돌고 있으면 남은 초가 보이고, 누르면 다시 펼쳐집니다.
- 홈 화면 위젯도 오른쪽 위 `▾`로 한 줄짜리 띠로 접을 수 있습니다. 접힘 상태는 기기마다 기억됩니다.

## 넘기는 방법

| 방식 | 동작 | 맞는 뷰어 |
| :--- | :--- | :--- |
| 키보드 키 | 뷰어 안에서 `→`(기본)·`←`·`↓`·PageDown·Space 키 이벤트를 보냄 | 페이지형 만화/EPUB/TXT |
| 스크롤 | 뷰어 안 스크롤 영역을 화면 높이의 90%만큼 내림 | 웹툰처럼 세로로 이어지는 뷰어 |
| 버튼 클릭 | 관리자가 지정한 CSS 선택자의 '다음' 버튼을 클릭 | 키 이벤트에 반응하지 않는 뷰어 |

간격·방식·키·동작 옵션은 사이드바 화면에서 **기기별로** 바꿀 수 있고(localStorage), 관리자 설정은 모든 사용자의 기본값입니다.

## 관리자 설정

| 키 | 설명 |
| :--- | :--- |
| `DEFAULT_SECONDS` | 기본 간격(1~600초) |
| `DEFAULT_METHOD` / `DEFAULT_KEY` | 기본 넘김 방식 / 보낼 키 |
| `NEXT_BUTTON_SELECTOR` | 버튼 클릭 방식에서 누를 '다음' 버튼 선택자 |
| `VIEWER_SELECTOR` | 뷰어 컨테이너 선택자. 비우면 "화면을 거의 다 덮는 고정 레이어"를 뷰어로 간주 |
| `HOTKEY` | 시작/정지 단축키 (예: `Alt+A`, `Shift+P`) |
| `SHOW_FLOATING` / `FLOAT_POSITION` | 뷰어 위 조작 버튼 표시 여부 / 위치 |
| `STOP_AT_END` | 마지막 페이지에서 자동 정지 |
| `RESET_ON_USER_INPUT` | 사용자 조작 시 카운트다운 초기화 |

## 동작 원리와 한계

- 코어에 "뷰어 안에서 플러그인 JS 실행" 계약이 없어서, 엔진(`engine.js`)은 이 플러그인의 화면(카테고리 탭/홈 위젯)이 처음 그려질 때 범용 플러그인 RPC(`action_id: get_engine`)로 받아 `window.YMAutoPage`에 상주합니다. 새로고침하면 다시 로드돼야 합니다.
- 마지막 페이지 판정은 뷰어가 `/api/media/progress`로 보내는 `page_idx`/`total_pages`를 **읽기만** 해서 합니다(요청은 그대로 통과). 마지막 페이지에서 한 번 넘겼는데 새 진행률 기록이 오지 않으면 멈춥니다. 다음 권이 자동으로 열리면 계속 넘깁니다. 스크롤 방식은 바닥에 닿으면 멈춥니다.
- 뷰어 자동 감지가 맞지 않으면 `VIEWER_SELECTOR`에 뷰어 최상위 요소의 선택자(개발자 도구로 확인)를 넣으세요.
- 키 이벤트는 브라우저가 "사람이 누른 키가 아님"으로 표시합니다. 뷰어가 `event.isTrusted`를 검사하면 키 방식이 안 먹으니 버튼 클릭 방식을 쓰세요.

## 콘솔 API

```js
YMAutoPage.start(); YMAutoPage.stop(); YMAutoPage.toggle();
YMAutoPage.setPrefs({ seconds: 15, method: 'key', key: 'ArrowLeft' });
YMAutoPage.getStatus();  // { running, viewerDetected, remainingSec, turns, progress, prefs }
```
